# Incident INC-003: PaymentService 503 Caused by Redis Pool Starvation

## Summary
PaymentService began returning HTTP 503 with a 38% error rate.
- Root Cause: A configuration deployment reduced MaxPoolSize from 200 to 50 in payment-production.json.
- Under traffic increase, Redis connections saturated at 50/50.
- Resolution: Increased MaxPoolSize from 50 to 200. Error rate immediately dropped to <1%.
